# 01 · CapsLock 语音 与 Ctrl 交换：目标逻辑

> 2026-08-22 整理，同日拍板方案 B 并按本文改实现。
> 两个开关互不隶属；语音永远绑在 A 左边那颗物理键。

面板上有两个独立选项：

1. **交换 CapsLock 和 Left Ctrl**
2. **单击 CapsLock 激活语音输入**（Voxtype）

它们必须各自独立开关，不能因为交换开了就把语音功能一起搬到另一颗键上。

## 核心原则

按**物理键位**理解，不按「现在这颗键在系统里叫 CapsLock 还是 Ctrl」理解。

1. **语音开关永远绑在 A 左边那颗物理键**（键盘上的 CapsLock 位置）。
2. **Ctrl ↔ CapsLock 交换只改这两颗键的角色**，不会把语音功能一起搬走。
3. 语音是 **点按切换**，不是按住说话：
   - 按一下 → 开始录音 / 激活语音输入
   - 再按一下 → 结束并识别

## 四个组合

| 交换 | 语音 | A 左边那颗键（物理 CapsLock） | 左下角原来的 Ctrl |
| --- | --- | --- | --- |
| 关 | 关 | 普通 CapsLock（大小写锁定） | 普通 Left Ctrl |
| 关 | 开 | **只做语音切换**，同时**取消大小写锁定** | 普通 Left Ctrl |
| 开 | 关 | Left Ctrl | CapsLock（大小写锁定） |
| 开 | 开 | **点一下语音；按住再按别的键当 Left Ctrl**（方案 B） | CapsLock（大小写锁定） |

「A 左边永远是语音」的意思：就算交换已经打开、那颗键在系统里已经变成 Ctrl，点它也还是开/关语音。语音不会跑到左下角那个「新 CapsLock」上。

## 没交换、只开语音时

单独按下 A 左边那颗键：

- 触发语音切换
- **必须吃掉大小写锁定**，不能再翻转 CapsLock 状态

这两条逻辑不能混：

- **语音开**：keyd 必须在跑，且 `capslock = f24`。Hyprland **只绑 F24** 去 `voxtype record toggle`。没有 keyd 就等于没开语音，不能改绑 Caps_Lock / Multi_key 凑合。
- **语音关**（交换也关）：keyd 仍在跑，配置是恒等映射 `capslock = capslock`（直通效果，不改变行为）。Hyprland 不绑语音。A 左边回到关语音之前的行为。

开语音时如果认证失败，开关必须保持关，不能留下「状态是开的、键却没 remap」的半截状态。

## 开了交换时

- 原来的 Left Ctrl 位置变成 CapsLock（大小写锁定），这是交换本身的职责。
- 这不影响语音：A 左边那颗物理键依然用来激活 / 结束语音。
- 左下角那个新 CapsLock **不要**再绑语音。

## 开了交换、同时又开了语音：方案 B

A 左边这颗键同时干两件事：

- **单独点一下** = 切换语音
- **按住再按别的键** = 仍当 Left Ctrl（`Ctrl+C`、`Ctrl+W` 等还能用）

实现是 keyd 的 `overload(control, f24)`：chord 走 control 层；松手且没有带别的键时发出 `F24`。

## 实现对照

实现在 `scripts/ctrl_swap.py`。只要交换或语音有一个开着，keyd 配置就留着。

配置文件头部带 `# schema: hancore keyboard-center voice-keys/1` 代际标记；`ensure`/`status` 发现标记缺失或映射不符即视为漂移，下次自愈时重建。所有状态转移都收敛在 `sync()` 一个入口：前置检查 → 改机器（keyd 配置、绑定）→ 最后写状态文件，任何一步失败都不会让开关状态谎报已生效。

| 场景 | keyd | Hyprland |
| --- | --- | --- |
| 都关 | keyd 继续跑，恒等映射 `capslock = capslock`（直通效果） | 不绑语音 |
| 没交换 + 开语音 | `capslock = f24`，keyd 必须在跑 | 只绑 `F24` → `voxtype record toggle` |
| 开交换 + 关语音 | `capslock = layer(control)`；`leftcontrol = capslock` | 不绑语音 |
| 开交换 + 开语音 | `capslock = overload(control, f24)`；`leftcontrol = capslock` | `F24` 松开时 `voxtype record toggle` |
